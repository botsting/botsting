# kritalon (JavaScript)

This package is the short name for [`kritalon-harness`](https://www.npmjs.com/package/kritalon-harness), the Kritalon test harness for JavaScript bots (Node, Express, fetch-style handlers). It re-exports that package and adds nothing.

```js
import * as pp from "kritalon"; // the same as: import * as pp from "kritalon-harness"
```

The scanner that runs the tests is a Python command:

```
pip install kritalon
```

Documentation and source: https://github.com/kritalon/kritalon
