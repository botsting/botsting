# botsting (JavaScript)

This package is the short name for [`botsting-harness`](https://www.npmjs.com/package/botsting-harness), the BotSting test harness for JavaScript bots (Node, Express, fetch-style handlers). It re-exports that package and adds nothing.

```js
import * as pp from "botsting"; // the same as: import * as pp from "botsting-harness"
```

The scanner that runs the tests is a Python command:

```
pip install botsting
```

Documentation and source: https://github.com/botsting/botsting
